# Code Of Conduct

## Our Standard

Coil should be a place where people can do rigorous technical work without harassment, intimidation, or exclusion.

Participants in this project are expected to:

- be respectful and direct
- argue from evidence
- critique ideas without attacking people
- help keep discussions useful for contributors and adopters

Unacceptable behavior includes:

- harassment or discrimination
- personal attacks
- deliberate intimidation
- doxxing or threats
- repeated bad-faith disruption

## Scope

This applies in:

- GitHub issues
- pull requests
- discussions
- project chat spaces
- public events or demos tied to Coil

## Enforcement

Project maintainers may remove comments, close threads, reject participation, or ban contributors for behavior that violates this code.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainers through the security or contact channel documented in this repository.

## Interpretation

This code is meant to keep the project usable for serious engineering collaboration. It is not a rhetorical shield against technical disagreement.
