---
title: Gitly Overview
---

Gitly exists to make one point clear: Davenda is not “commerce only.”

It applies the same platform ideas to a developer-product shape:

- repository and organization surfaces
- multi-locale UX
- theme switching
- mock scheduled tasks
- mock API routes
- linked Rust customer logic
- WASM extension boundaries

If Shoppr answers “can this framework carry a serious storefront?”, Gitly answers “can it carry a product that is obviously not a storefront?”

The answer should be yes in both cases.
