# Support

Use the right channel for the right kind of problem:

- Bug reports: open a GitHub issue with a minimal reproduction.
- Feature ideas: open a GitHub issue describing the product gap or missing capability.
- Security issues: do not file them publicly. Follow [SECURITY.md](./SECURITY.md).
- General usage questions: start with the docs site and the demo app READMEs, then open a discussion or issue if the gap is documentation rather than a defect.

When reporting a problem, include:

- the Coil version or commit SHA
- the demo or customer app involved
- exact commands run
- relevant logs or screenshots
- what you expected versus what happened
