# Roadmap

Coil is being shaped as a product-focused Rust web framework with a strong ecommerce core and a wider application model.

Current priorities:

- make the public docs and onboarding path production-grade
- deepen Shoppr as the reference ecommerce app
- keep Gitly proving the non-commerce story
- tighten customer-root workspaces and linked Rust backend ergonomics
- harden operations, observability, and release automation

Near-term areas of focus:

- richer admin authoring and operational workflows
- higher-fidelity demo content and interactions
- better crates.io packaging metadata and release discipline
- broader docs coverage for composition, deployment, and extension models

This file is directional, not a contract. The architecture records in `docs/design/` remain the source of truth for accepted design.
