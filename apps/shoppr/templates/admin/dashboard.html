Linked customer backend

Workspace-owned Rust hook path

Shoppr ships a linked Rust backend crate through the customer workspace itself. The running store exposes that linked plugin metadata directly in the runtime render model, so this admin view can show exactly which first-party customer hooks are compiled into the app.

This is the primary first-party Rust customization path for Shoppr. The optional sidecar and WASM paths still exist, but they are secondary and bounded.

From the Shoppr workspace itself, run cargo run -p shoppr -- linked-backend demo to execute the checked-in linked backend rules without the optional sidecar.
