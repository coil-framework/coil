---
title: Welcome To Davenda
---

Davenda is a Rust web framework for teams who want the framework and the product shape to line up.

The key idea is simple:

- lead with real application concerns
- keep the platform opinionated
- make extension boundaries explicit
- use demos that feel like actual products instead of framework toys

If you are a Rust web developer evaluating Davenda, start here:

1. Read the [Quickstart](getting-started/quickstart.md).
2. Run Shoppr locally.
3. Follow the ecommerce guides to understand the default path.
4. Use Gitly to see how the same platform applies outside ecommerce.
5. Drop into the architecture section when you want the deeper system model.

Davenda does not try to be everything to everyone. It is optimized for product teams who want:

- HTML-first rendering with progressive enhancement
- a clean customer-app story
- multi-site and multi-locale capability
- strong auth and operational boundaries
- a first-party Rust customization path
- a bounded third-party extension model
