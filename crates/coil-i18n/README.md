# coil-i18n

`coil-i18n` provides internationalisation and localisation primitives for Coil.

It contains the core structures used for locale-aware content, translation catalogues, and other language-sensitive parts of the platform.

## Install

```toml
[dependencies]
coil-i18n = "0.1.0"
```

## When to use this crate directly

- You are composing Coil manually and need locale-aware primitives.
- You are building or extending translation and localisation behaviour.
- You are contributing to the platform’s multilingual support.

## Related crates

- `coil-a11y`: accessibility primitives that often work alongside localised content.
- `coil-seo`: locale-aware SEO metadata support.
- `coil-runtime`: route and request handling across sites and locales.
