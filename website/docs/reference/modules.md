---
title: Official Modules
---

Davenda’s official modules are batteries, not random examples.

Current module families include:

- CMS
- commerce
- memberships
- events
- admin
- media
- ops

## How To Think About Them

- core owns the platform primitives
- official modules own reusable domain batteries
- customer apps own product-specific composition

That separation is central to Davenda’s design.
