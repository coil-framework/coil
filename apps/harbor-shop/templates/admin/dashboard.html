Linked customer backend

Workspace-owned Rust hook path

Harbor Shop ships a linked Rust backend crate through the customer workspace itself. The running store exposes that linked plugin metadata directly in the runtime render model, so this admin view can show exactly which first-party customer hooks are compiled into the app.

This is the primary first-party Rust customization path for Harbor Shop. The optional sidecar and WASM paths still exist, but they are secondary and bounded.
